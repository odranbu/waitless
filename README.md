
# WaitLess - Queue Management App

## ✅ STATUS: DEPLOYMENT READY (Fixed)

This application has been rebuilt for stability, performance, and reliable routing.
The configuration has been patched to ensure React 18 compatibility.

### 🚀 Quick Start

1.  **Install dependencies:** `npm install`
2.  **Run development server:** `npm run dev`
3.  **Build for production:** `npm run build`
4.  **Start production server:** `npm start`

### 🔑 Configuration (Optional)

The app includes **Automatic Demo Mode** for all external services (Stripe, Google AI). It will run immediately without API keys.

To enable real features, create a `.env.local` file:

```env
# Stripe Configuration
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
STRIPE_PRICE_ID=price_...
STRIPE_WEBHOOK_SECRET=whsec_...

# Google Gemini AI
API_KEY=...
```
